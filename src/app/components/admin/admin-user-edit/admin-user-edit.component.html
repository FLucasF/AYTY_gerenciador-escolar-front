Nome é obrigatório. Nome deve ter no mínimo 3 caracteres.
CPF é obrigatório. CPF deve conter exatamente 11 dígitos numéricos.
Email é obrigatório. Formato de email inválido. Exemplo: nome@gmail.com.
A senha deve ter pelo menos 8 caracteres. A senha deve conter ao menos uma letra maiúscula, uma minúscula, um dígito e um caractere especial.
Setor é obrigatório para administradores.
SIAPE é obrigatório para administradores. SIAPE deve conter exatamente 7 dígitos numéricos.
Departamento é obrigatório para professores.
SIAPE é obrigatório para professores. SIAPE deve conter exatamente 7 dígitos numéricos.
Curso é obrigatório para alunos.
